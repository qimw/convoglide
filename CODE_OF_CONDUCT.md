# Code of Conduct

## Our Commitment

We want ConvoGlide to be a welcoming, respectful project for contributors and users from different backgrounds, experience levels, and regions.

## Expected Behavior

Please:

- be respectful and constructive
- focus on ideas, evidence, and implementation details
- assume good intent while still giving honest technical feedback
- help keep discussions accessible for people who are newer to performance work or browser tooling

## Unacceptable Behavior

This project does not welcome:

- harassment or personal attacks
- hateful or discriminatory language
- intimidation, doxxing, or threats
- deliberate disruption, spam, or bad-faith behavior

## Scope

This code of conduct applies to:

- GitHub issues
- pull requests
- code review discussions
- benchmark and performance discussions in project spaces

## Enforcement

Project maintainers may remove or moderate comments, issues, pull requests, or contributors whose behavior harms the project environment.
