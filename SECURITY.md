# Security

## Supported scope

ConvoGlide is currently an experimental browser-side optimization project for ChatGPT Web.

## Reporting a security issue

Please do not publish sensitive findings together with:

- account cookies
- access tokens
- private conversation content
- raw browser profiles

Open a private security report if the issue could expose credentials or private chat data.

## Current security posture

- local-only browser execution
- no intended conversation upload path
- no bundled third-party analytics

## Important note

Because ConvoGlide runs inside a browser session, contributors and users should treat browser profiles, remote debugging sessions, and userscript managers as sensitive local surfaces.
